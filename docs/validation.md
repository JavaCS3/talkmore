## 初版 CLI 验证（2026-10-05）

- uv 已安装依赖并生成 `uv.lock`；初版 4-bit 模型运行文件实际下载总量 542.1 MB。
- 8 项测试通过，覆盖超过 1 GB/未知大小的下载拦截、使用本地模型无需网络，以及录音停止/启动失败时释放设备。
- 设置 `HF_HUB_OFFLINE=1`，用 macOS 系统语音合成的中文 WAV 完成真实 Metal 推理，输出与测试句子一致：`今天下午需要跟客户确认一下项目的交付时间。`
- 此单次短音频测试：加载 0.24 秒、推理 1.97 秒、进程峰值 RSS 677 MiB、MLX 峰值 625 MiB。不是预热后的性能基准，也不能代表中文口语或更长音频表现。
- 麦克风流程已通过模拟设备测试，尚未完成真实麦克风录音验证。请运行 `uv run talkmore record` 做首次试用。
- 沙箱/无头环境可能无法访问 Metal GPU，需在正常 macOS 终端运行。

### 模型切换验证（2026-10-05）

默认已改为 8-bit，支持 `--model 4bit` / `--model 8bit`，保留完整模型 ID 和本地目录。13 项测试通过。8-bit 必要文件下载总量为 840.1 MB，下载前经 1 GB 阈值检查；4-bit 缓存保留。

两次分别启动 CLI，设置 `HF_HUB_OFFLINE=1`，转写同一段 4.74 秒中文合成 WAV，均输出：`今天下午需要跟客户确认一下项目的交付时间。`

| 模型 | 加载时间 | 推理时间 | 进程峰值 RSS | MLX 峰值 |
|---|---:|---:|---:|---:|
| 4-bit（通过简写选择） | 0.30 秒 | 0.23 秒 | 666 MiB | 639 MiB |
| 8-bit（默认选择） | 0.17 秒 | 0.29 秒 | 950 MiB | 923 MiB |

这些是单次运行结果，可能受系统缓存影响；不是冷启动/预热性能基准。单句识别一致无法证明两者在自然口语上的准确率相同。进程 RSS 和 MLX 峰值存在重叠，不能相加。

### 菜单栏 MVP 验证（2026-10-05）

- 65 项自动测试通过，覆盖录音生命周期、300 秒超时与手动停止去重、异步取消、快捷键事件、配置持久化、剪贴板写入顺序、修饰键等待、取消和单次系统粘贴。macOS 桥接测试构造真实键盘事件并 mock 发送接口，不向实际应用发送按键。
- 在正常 macOS 图形会话中，以模拟模型和权限验证菜单栏、录音浮层、设置窗口的创建与关闭；原生框架导入及权限检查可用。
- 使用本机 Tingting 语音合成生成 4.74 秒中文音频，再重复截取为精确 300 秒音频；离线使用默认 8-bit 模型，在同一 Session 中完成真实 Metal 推理：

| 输入 | 推理时间 | 进程峰值 RSS | MLX 峰值 |
|---|---:|---:|---:|
| 4.74 秒合成短句 | 0.31 秒 | 949 MiB | 923 MiB |
| 300 秒重复合成语音 | 9.95 秒 | 1083 MiB | 1167 MiB |

此次模型加载 0.39 秒，短句转写与测试文本一致。长音频输出 1330 字符；这是单次合成音频测试，不是自然口语准确率或稳定性能基准。峰值属于同一进程的累计统计，RSS 与 MLX 统计有重叠，不能相加。

已在正常 macOS 会话中验证私有事件源及完整 Cmd+V 四个事件可以创建；发送接口被 mock，没有实际粘贴。录音浮层之前已验证显示时不会改变前台应用，也不会成为 key/main window。当前工具进程缺少输入监控和辅助功能权限，真实全局快捷键及新链路下的跨应用粘贴仍待实机验证。

授权后请在 TextEdit、Chrome、Codex/Electron、VS Code 中检查：右 Option 开始/停止，组合输入不误触，浮层显示前后键盘输入仍在原输入框，选区替换，停止后仅粘贴一次且不提交，Esc 取消，连续多轮及完整 5 分钟录音。另检查权限拒绝/恢复及休眠取消。当前链路不依赖目标应用的辅助功能输入框或 caret 支持。
